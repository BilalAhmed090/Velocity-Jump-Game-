🎮 Jump Game

A 2-player turn-based racing strategy game built with Python and Pygame. Players compete to collect checkpoints while managing velocity, avoiding obstacles, and planning their moves strategically.

🚀 Features
-> Two-player turn-based gameplay
-> Velocity-based movement system
-> Custom race track mode
-> Random obstacle course mode
-> Collectible checkpoints (Blue & Green)
-> Score tracking
-> Collision detection and crash effects
-> Interactive HUD and game interface

🛠️ Built With
-> Python 3
-> Pygame

📦 Installation:

-> Clone the repository:
git clone https://github.com/yourusername/jump-game.git
cd jump-game

-> Install Pygame:
pip install pygame

-> Run the game:
python jump_game.py

  🎮 Controls
Key	Action
⬅️ ➡️ ⬆️ ⬇️	Adjust velocity
Enter	Confirm move
-> N	Switch to Random Track
-> M	Switch to Race Track
-> I	Return to Main Menu
-> R	Restart Game
-> ESC	Quit

🏆 How to Play
Start from the designated starting position.
Collect the Blue checkpoint first.
Then collect the Green checkpoint.
Avoid crashing into walls, obstacles, or your opponent.
The first player to complete the objective wins.
